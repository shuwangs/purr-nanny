# A → B integration proposal (2026-10-12)

Python confirmed. A owns server/, infra/, docs/contracts.md, root pyproject.toml, and tests/test_platform*.py. B owns storage/, packages/cat-health-signals/, demo/, B tests, docs/rules.md. A's server/backend.py is a local reference fixture, not production storage or rules.

Integration entry: implement an adapter exposing `execute(tool: str, args: dict, principal: server.identity.Identity, now: datetime) -> dict`, or supply repository + rules APIs and A will implement the adapter. All datetimes passed by A are aware UTC; args are Pydantic-validated and serialized JSON. Identity supplies trusted household_id and timezone; caller cannot supply either. Backend exception `server.backend.DomainError(code, message)` maps to sanitized tool errors. Reference backend demonstrates idempotency and household isolation. `build_app(backend=...)` supports injection.

Schemas are in server/contracts.py (eight MODELS). Cat: cat_id, name (extend after agreement). Health event types vomiting/appetite/litter/energy/weight; care feeding/water/litter_cleaning/medication/food_change. Input: cat_id, idempotency_key, optional event_id, optional occurred_at (aware), optional reporter, details object (unknown values must remain unknown), source user|seed. Follow-up sends same event_id, same type/cat/source, fresh idempotency_key; merges supplied details. recorded_at stays original; updated_at changes; occurred_at defaults to explicit service now with time_defaulted=true.

Output envelope: schema_version='1.0', event_id=null|string, logged=bool, follow_up=[], red_flags=[], patterns=[], notification_status={state:'disabled'}. Additional event/cat/events/window/includes_sample_data/analysis_status fields allowed. Red flag shape proposed: rule_id, level (urgent|warning), evidence array, recommended_wording. Follow-up proposal: field, question. Missing rules must report analysis_status='unavailable'; never imply no risk. Notification layer consumes red_flags after backend execution.

Queries use start-inclusive/end-exclusive UTC window plus timezone. get_today uses household-local midnight boundaries. WindowQuery days=1..90 defaults 7. A will defer clinical thresholds and event detail schemas to B. Please record your confirmed interfaces and deviations below or in docs/rules.md; A can adapt without changing public schemas prematurely.
